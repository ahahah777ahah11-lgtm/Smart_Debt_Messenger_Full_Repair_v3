# Smart Debt Messenger — Android WebView project

Arabic RTL customer-debt tracker, packaged as an Android WebView application.

## Features
- Responsive mobile-first Arabic UI.
- Customer creation, search by name/phone, debtor/creditor filters, delete.
- Separate amounts owed by customer (`عليه`) and amounts owed to customer (`له`). Net debtor balance is `max(0, عليه - له)`.
- Balance adjustments and payment recording (payments reduce `عليه`, down to zero).
- Local persistence on this device through WebView localStorage.
- CSV/JSON import and CSV export. XLS/XLSX import works when the SheetJS script can be loaded online; offline users should export Excel to CSV first. PDF tables are not parsed directly.
- SMS opens the messaging app with a prefilled message for user review; it does not silently send messages.

## Build
Open the `html-to-apk-builder` folder in Android Studio or a compatible Android/Gradle IDE. Use JDK 17, Android SDK 34, and Gradle 8.5 / Android Gradle Plugin 8.2.2. Or push this repository to GitHub and run **Build Smart Debt Messenger APK** under Actions; download the generated artifact.

The workflow builds debug and release variants. The release APK generated by this workflow is unsigned and is not a Play Store-ready signed release.

## Important data notes
Data is stored locally in the app's WebView storage; uninstalling or clearing app data can remove it. Export CSV regularly. Test imported columns with a copy of your data before relying on it for accounting. No accounting database is uploaded to a server.
